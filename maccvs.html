MacCVS

A native SwiftUI CVS client for macOS — a successor to the discontinued Carbon cvsgui MacCVS.

MacCVS on GitHub → Download (notarized zip) User guide

What it is

MacCVS is a native macOS client for CVS, written in SwiftUI with AppKit where needed. It replaces the original Carbon-based cvsgui MacCVS, which stopped running when macOS removed Carbon and 32-bit support. It works on existing working copies (checked out with cvs checkout) and runs every operation through a cvs binary bundled inside the app, so working copies remain ordinary CVS working copies.

Features

  • Column browser (NSBrowser). Column 0 is a project switcher listing the working copies opened so far; each can be given a display name, forgotten, or revealed in Finder.
  • File list with per-file CVS status (Modified, Added, Removed, Needs update, Needs merge, Conflict, Missing, Unknown) and revision, sortable by name, status or revision.
  • Local change detection without the server. A file's modified state is computed from its mtime against the timestamp in CVS/Entries, the same test cvs uses; an FSEvents watcher re-checks on every save.
  • Prefetched base revisions. When a file becomes modified, its base revision is fetched in the background and cached, so a diff opens without a network round-trip.
  • Diff window: side-by-side or unified, line- or word-level highlighting, a draggable centre divider, several files in one window, per-hunk Discard and per-file Discard all (reverse-applies the hunk to the working file), and a Commit button for the files shown.
  • Operations: Update (current directory, non-recursive, or the selection), Commit with a per-file picker, Add, Revert (cvs update -C), Log.
  • History window: cvs log parsed into revision, author, date, ± line counts and message; Show diffs loads the diff each revision introduced, on demand.
  • Console showing every command run and its output.
  • Session restore: last working copy, directory, file selection and sort order.
  • Self-update from GitHub Releases (daily check; the download's notarization is verified before it replaces the app).

Command line

MacCVS=/Applications/MacCVS.app/Contents/MacOS/MacCVS
"$MacCVS" /path/to/workingcopy     # open a working copy
"$MacCVS" --diff a.c b.c c.c       # CVS diffs of several files, one window
"$MacCVS" --compare LEFT RIGHT     # visual diff of any two files

In --diff / --compare mode only the diff window is shown and the app exits when it is closed, so it can serve as a git difftool: git config --global difftool.maccvs.cmd '/Applications/MacCVS.app/Contents/MacOS/MacCVS --compare "$LOCAL" "$REMOTE"'.

Requirements

  • macOS 14 or later, Apple silicon or Intel (universal binary), Developer ID signed and notarized.
  • No CVS installation needed: GNU CVS 1.11.23 is bundled (built per-arch from source, linking only libSystem).
  • :pserver: passwords are read from ~/.cvspass (written by cvs login).

Limitations

  • No checkout, login, remove, tag, branch, annotate or import; use cvs in Terminal for those.
  • Alpha releases (v0.7-alpha).
