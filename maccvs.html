MacCVS

CVS, as a proper Mac app.

Browse a working copy, see what you've changed the moment you save, read clear diffs, throw away the bits you don't want, then commit or update. A native successor to the old Carbon MacCVS, with its own cvs built in.

What it's for

The CVS client the Mac lost

For years MacCVS was how Mac users worked with CVS. It was written for Carbon, and when macOS dropped Carbon and 32-bit apps it stopped running. This is a new one, written from scratch in SwiftUI, for the many projects still kept in CVS.

Changes show up as you save

A file turns Modified the moment you save it, worked out locally the same way cvs does. No server round trip.

Diffs you can read

Side by side or unified, by line or by word, with several files in one window. Opens instantly: the base revision is fetched ahead of time.

Undo one change, keep the rest

Each change in a diff has its own Discard button, so you can drop a debugging line without losing the work around it.

Nothing else to install

GNU CVS 1.11.23 is built in, for Apple silicon and Intel. Your working copies stay ordinary CVS working copies.

How it works

Open a working copy, and you're in

MacCVS works on folders you've already checked out with cvs checkout. Your login and server settings come from the working copy itself and from ~/.cvspass.

1

Open it

File ▸ Open Working Copy… (⌘O) and choose the module's top folder. It joins the list of projects in the left-hand column, and comes back next time you start.

2

Find your changes

Click through folders in the column browser. Each file shows its status and revision, coloured so changed files stand out. Sort by status to put them at the top.

3

Diff, then commit

Double-click a file for its diff. When it looks right, press Commit (⌘K), tick the files to include, write a message, and send it.

The diff window

Exactly what changed

Select one or more files and press Diff (⌘D). Every file you picked appears in one window, one after the other.

  • Side by side or unified, with a divider you can drag to give either side more room.
  • Line or word highlighting. Word mode marks only the characters that changed, which makes a changed number or name easy to spot.
  • Instant. As soon as a file becomes modified, MacCVS fetches the revision you started from and keeps it, so the diff needs no trip to the server.
  • Works on any two files, not just CVS ones: see the command line.

Discard

Keep the work, drop the leftovers

Each change in the diff window has a Discard button. It puts just that part of the file back the way it was, and leaves your other changes alone. Discard all does the whole file.

Then commit straight from the diff window: its Commit button opens the commit sheet with the files you're looking at already ticked.

Staying in step

Update, add and revert

  • Refresh (⌘R) asks the server what's new. Files a colleague has committed show Needs update, in blue.
  • Update (⌘U) brings in their changes, for the folder you're in or just the files you've selected.
  • Add puts a new file under CVS. Turn on View ▸ Show Non-CVS Files (⌘⇧U) to see files CVS doesn't know about yet.
  • Revert throws away all your local changes to a file and gets a fresh copy from the server.
  • Every command and its output appears in the console at the bottom of the window, so you always know what was run.

History

Who changed what, and why

Select a file and choose Log (⌘L). The history window lists every revision, newest first, with its author, date, lines added and removed, and the commit message.

Turn on Show diffs to see the change each revision made, right under its message. Diffs load as you scroll, so long histories stay quick.

Command line

A diff tool for Terminal, too

The diff window works from Terminal. Give it CVS files to see their changes, or any two files to compare them. In this mode MacCVS shows only the diff window, and quits when you close it.

That makes it a good git difftool:

git config --global difftool.maccvs.cmd \
  '/Applications/MacCVS.app/Contents/MacOS/MacCVS --compare "$LOCAL" "$REMOTE"'
# the app itself
MacCVS=/Applications/MacCVS.app/Contents/MacOS/MacCVS

# open a working copy
"$MacCVS" ~/Projects/bakery

# CVS diffs of several files, in one window
"$MacCVS" --diff orders.tcl prices.tcl

# compare any two files
"$MacCVS" --compare old.txt new.txt

Good to know

What it does and doesn't do

MacCVS covers the everyday work: status, diff, discard, commit, update, add, revert and history. It updates itself from GitHub, checking once a day, and checks that each download is notarized before installing it.

It doesn't check out, log in, remove, tag, branch, annotate or import. Use cvs in Terminal for those. It's still an alpha release.

MacCVS

A native macOS client for CVS, written in SwiftUI with AppKit where needed, by John Buckman. It runs every operation through its own copy of GNU CVS, so working copies remain ordinary CVS working copies.

Open source under the GNU GPL v3.0. Screenshots use a demo repository.
