Blink

A file viewer that's open before you've finished double-clicking.

Pictures, PDFs, spreadsheets, email, GPS routes, video, audio, text and Markdown, each in its own window. Zoom in, zoom out, fit to the window. That's all it does, so it starts in about half the time Preview takes.

What it's for

Look at a file, then get on with it

Preview, QuickTime, Excel and Mail each take a second or more to start, just to show you something. Blink shows it straight away.

Fast to open

About 0.6 s from a double-click to the picture when Blink isn't running, and about 0.2 s when it is. Preview takes 1 to 1.2 s.

One window per file

Open five files and you get five windows, each named after its file. Opening a file that's already open brings its window forward.

Zoom in, out and to fit

The same four buttons and keys in every window: ⌘+ ⌘− ⌘0 ⌘1.

Out of the way

Close the last window and Blink leaves the Dock and waits as an eye in the menu bar, ready for the next file.

Formats

What it opens

Each kind of file gets the view that suits it. Blink can be the default app for all of them, so a double-click in Finder opens Blink.

Pictures jpg png heic avif tiff webp

Opens at a size that fits the screen. Rotated phone photos come up the right way round. Multi-page TIFFs show every page.

Animations gif avif

Animated GIF and AVIF play, each frame for as long as the file says.

PDF

Every page in one scrolling column, with text you can select and copy.

Tables csv xlsx

A grid with row numbers. Excel files show their values and one tab per sheet.

Email eml

The message, its pictures and its attachments. Images from the internet stay blocked until you ask for them.

GPS routes gpx

The route on OpenStreetMap or a topographic map, with distance, climb and time.

Markdown md

The text and the formatted page side by side. Both update when the file is saved.

Video and audio mp4 m4a

Apple's standard player controls. Space plays and pauses.

Text txt and anything else

Plain text in a fixed-width font, in whatever encoding the file uses.

Pictures

Fit, zoom, actual size

A picture opens fitted to its window and keeps fitting as you resize the window. Zoom in and you can scroll around it; 1:1 shows it at its real size.

  • Zoom steps like Preview's, up to 32×, with sharp pixels when you're close in.
  • Pinch on a trackpad to zoom smoothly.
  • Animated GIF and AVIF play as soon as they open.

Markdown

The text and the page, side by side

On the left, the Markdown as written. On the right, the page it makes, with tables, task lists and code blocks the way GitHub shows them.

Scroll either side and the other follows. Save the file in your editor and both sides update, keeping your place. Drag the divider to give either side more room.

GPS routes

Where the walk went

A GPX file opens as a map, zoomed to fit the route. Start and end are flagged, and named waypoints are pinned. Along the bottom: the route's name, distance, total climb and time taken.

  • Map is OpenStreetMap; Topo is OpenTopoMap, with contour lines and hill shading.
  • Map tiles are kept on disk, so a route you've opened before shows at once.

Email

Read a saved message without opening Mail

From, to, date and subject at the top, then the message as it was sent, with the pictures that came with it. Click an attachment to open it.

Pictures linked from the internet, the kind used to tell a sender you opened their message, stay blocked. Press Load Remote Images if you want them.

Tables

CSV and Excel files

CSV files open as a grid with the first line as column headings. Commas, semicolons and tabs all work, and quoted text can hold any of them.

Excel files show column letters and row numbers like Excel, with a tab for each sheet. Zoom makes the text bigger or smaller.

PDF and video

Documents and movies

PDFs scroll as one long column of pages, fitted to the window's width. Videos open at their own size, shrunk if they're bigger than the screen; zooming makes the window bigger or smaller.

Speed

How fast is fast

Time from opening a file to its window appearing, on a MacBook Air M4 with macOS 26.

Picture, app not running0.6 s1.0 s
PDF, app not running0.6 s1.2 s
Picture, app already running0.23 s0.64 s

Turn on Open at Login and it's about 3 times faster again. Blink then starts when you log in and waits as an eye icon in the menu bar at the top of the screen, so a file opens in about 0.2 s instead of 0.6 s. Blink turns this on the first time you run it. To turn it off, click the eye in the menu bar and untick Open at Login.

An app that does nothing at all takes about 0.5 s to show a window on the same Mac, so there isn't much left to save on a cold start. Staying running is what makes the big difference.

How

Why it starts quickly

  • A plain AppKit app: no document framework, no saved window state to restore.
  • The program itself only knows pictures, text and tables. PDF, web pages, maps and video live in a separate library that loads the first time you open one of those.
  • The zoom buttons are text, not icons: loading the icon font cost 70 ms.

Good to know

What it doesn't do

Blink only shows files. It doesn't edit, mark up, rotate, crop, export or print; use Preview for those. File ▸ Open in Preview hands the file over.

Excel files show cell values, not colours, charts or formatting. Other Office files (Word, PowerPoint, Numbers) open in Apple's Quick Look view. To make Blink the default for a kind of file, use Finder's Get Info ▸ Open with ▸ Change All.
