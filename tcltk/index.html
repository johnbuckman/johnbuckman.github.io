Tcl/Tk, everywhere

Real Tcl/Tk on iPhone, iPad, Apple Silicon, Android and the web.

Ports of AndroWish and undroidwish (Tcl/Tk drawn with SDL2, with the full AndroWish extension set) to platforms the upstream project doesn't build for. Plus the libraries that run the Decent Espresso tablet app on them: Bluetooth LE for macOS and Linux, OAuth 2.0, and faster BLT graphs.

Why I built these

An espresso machine's app

I make espresso machines, and our tablet software is written in Tcl/Tk. These projects are how that one program reaches Android tablets, iPads, old iPads, Macs, Linux and a web browser, talking Bluetooth to the machine and its scale on each. Everything is open source, in case it helps your Tcl/Tk program travel too. — John Buckman

  • One Tk codebase, unchanged across every platform.
  • Bluetooth LE everywhere: Android, iOS, macOS and Linux all answer the same ble command.
  • No App Store needed on iPhone and iPad: SideStep installs and updates it.
